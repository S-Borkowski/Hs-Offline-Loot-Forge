HS Offline Loot Forge v2.7.9 - Hero Siege 7.0.5.0 Update
================================================

IMPORTANT
---------
- Offline / single-player use only.
- Loot Forge temporarily patches the running Hero_Siege.exe process.
- It never modifies Hero_Siege.exe on disk.
- Use one target route at a time.
- Restore All or closing Loot Forge restores active routes before releasing its private proxy page.
- Hero Siege must be launched without Easy Anti-Cheat (EAC).
- Keep backups of important offline save files.

INSTALLATION
------------
1. Download HSOfflineLootForge-v2.7.9.zip from the official GitHub release.
2. Extract the complete ZIP to a normal folder.
3. Do not run the EXE from inside the ZIP preview.
4. The build is not code-signed. Windows SmartScreen may show a warning for this community tool.

GETTING STARTED
---------------
1. Start Hero Siege with Launch Without EAC and enter offline mode.
2. Start HSOfflineLootForge.exe and accept the administrator prompt.
3. Click Attach / Select.
4. If the build cannot be resolved, click Auto Resolve Build once.
5. Choose one Quick Farm profile or one Boost Vault route.
6. Kill normal monsters to test the selected target.
7. Use Restore All before changing to an unrelated target.

QUICK FARM PROFILES
-------------------
- Angelic Farm: activates the verified Season 10 Angelic / SS rarity route.
- Unholy Farm: activates the verified Unholy item focus.
- Heroic Farm: activates the native Heroic item route.
- Uncut Jewel: routes normal-monster drops to the native Jewel-category Uncut Jewels.
- Materials Farm: activates the verified Ore Materials route.
- Rare Material Gates: activates Random Orbs.
- Tarot Farm: activates normal Tarot Card drops.
- Divine Tarot: activates Season 10's separate native Divine Tarot route.
- Reset Farm: restores every active runtime route.

BOOST VAULT

Rarity & Focus
- Angelic / SS Drops, Angelic Focus, Heroic Focus and Unholy Focus
- Satanic Items, Unique Flasks and Relics

Cards & Keys
- Tarot Cards, Divine Tarot, Codex, Angelic Keys, Satanic Dice, Keys and Dungeon Keys

Charms & Gems
- Normal, Angelic, Unholy and Satanic Charms
- Satanic Charms also includes the working Set Charm pool
- Uncut Jewels, green Incarnation Gems and Boss Gems

Materials & Crafting
- Ore Materials, Essence of Chaos, Random Orbs and Life / Mana Flasks
- Satanic Crystal, Blacksmith's Mallet, Destiny Shard
- Gypsy's Prophecy, Prophet's Wisdom, Runes and Reflection

BUTTON STATES
-------------
- STANDBY: the game is not attached or the native dispatch table is not ready yet.
- OFF: the route is available but inactive.
- ON: the selected runtime route is active.
- PARTIAL: only part of a route is present. Use Restore All before continuing.
- MISMATCH: bytes do not match the verified build. Use Restore All, restart the game, then try Auto Resolve Build.

TROUBLESHOOTING
---------------
- No drops: confirm that the button says ON and test normal monsters in a combat zone.
- STANDBY after attaching: click Auto Resolve Build, then Refresh Status.
- MISMATCH: click Restore All and restart both Hero Siege and Loot Forge.
- Game freeze or crash: close the game, reopen it, then use only one route at a time.
- Module base / memory access error: fully close Hero Siege, relaunch it without EAC, then reopen Loot Forge.
- Permission error: accept Loot Forge's administrator prompt and keep the game running without EAC.
- Antivirus warning: verify that the download came from the official GitHub release and compare SHA256SUMS.txt.

KNOWN SAFETY EXCLUSIONS
-----------------------
- Boss Parts is hidden because it produced no visible normal-monster drops.
- Standalone Set Charm focus is hidden because the tested route froze the game; Satanic Charms already drops both pools.
- Heroic Charm focus is hidden because its Season 10 repository mapping is not verified.
